
# AppTimeTracker

Windows приложение для отслеживания времени использования программ с подробной статистикой.

## 📊 Возможности

- **Отслеживание процессов в реальном времени** - мониторинг всех запущенных приложений
- **Автоматическая фильтрация** - встроенный черный список системных процессов
- **Группировка процессов** - синонимизация имен (chrome.exe, Chrome, chrome)
- **Детальная статистика** - графики и таблицы по дням, неделям и месяцам
- **Работа в системном трее** - собственная реализация без внешних зависимостей
- **Темная тема** - современный темный интерфейс
- **Автозагрузка с Windows** - автоматический запуск при старте системы
- **Кэширование иконок** - быстрая загрузка интерфейса

## 📦 Установка

1. Перейдите в раздел [Releases]
2. Скачайте последнюю версию архива 
3. Распакуйте архив в любую папку
